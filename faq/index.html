常见问题 · FAQ

  • 问：我在哪里可以获得这个模组？
    英文原文
    Q: Where can I get the mod?
  • 答：该模组目前仍处于公开测试阶段。pak 文件通过 Practical DRG 社区发布——可加入其 Discord 服务器获取官方公告与最新版本；另有深岩资源站整理了下载、难度表与中文教学（详见资源页的「获取 CD2」）。推荐使用 Mod Integration Loader 来加载模组。
    英文原文
    A: The mod is still in open beta. The .pak file is distributed through the Practical DRG community — join their Discord server for official announcements and the latest build. There is also a Chinese resource site mirroring downloads, tier lists and Chinese guides (see Get CD2 on the Resources page). The Mod Integration Loader is recommended for loading it.
  • 问：我能同时使用 CD1 和 CD2 吗？
    英文原文
    Q: Can I use this at the same time as CD1?
  • 答：不可以，一次只能启用一个 CD 版本。如果你在启用 CD2 的情况下要加入使用 CD1 的房间，并希望避免补给硝石消耗不同步，可以使用 cd1-client.pak——它可在 Practical DRG 的 Discord 以及深岩资源站获取。
    英文原文
    A: No — only one CD version can be enabled at a time. If you want to join CD1 lobbies while running CD2, and avoid the desync in the nitra cost of resupplies, there is a cd1-client.pak for that. It is available from the Practical DRG Discord and from the Chinese resource site.
  • 问：我该如何使用它？
    英文原文
    Q: How can I use this?
  • 答：将 zip 文件拖入 MINT 并点击 Install Mods 即可安装，不需要从 zip 中解压 pak 文件。
    英文原文
    A: Drag and drop the zip file into MINT and press install mods. You do not need to extract the pak from the zip to install.
  • 问：我该从哪一页开始学？
    英文原文
    Q: Where should I start reading?
  • 答：先看《CD2 基础》了解界面与难度文件的整体结构；再看《模块》了解顶层字段（Enemies、Direct、WaveSpawners、Mutators 等）；动手写条件时把《Mutators》当手册随时查；遇到行为不符预期时对照《写作提示与常见错误》。
    英文原文
    A: Start with the Basics to learn the GUI and the overall structure of a difficulty file. Then read Modules to understand the top-level fields (Enemies, Direct, WaveSpawners, Mutators …). Keep Mutators open as a reference while you write conditions, and check Tips when something does not behave as expected.
  • 问：客户端想进入我 CD2 的房间必须安装 CD2 吗？
    英文原文
    Q: Do clients need CD2 to play in my CD2 lobby?
  • 答：取决于你的难度用到了哪些功能。CD2 的部分功能必须同步给客户端，例如敌人缩放控制 Scale 与敌人外观（材质）。敌人模块有 Enemies 与 EnemiesNoSync 两种形式，二者不可同时使用：Enemies 会把这些特征同步给客户端，但代价是客户端必须安装 CD2，否则任务开始时会被断开连接；改用 EnemiesNoSync 后客户端就无需安装 CD2，代价是这些特征在客户端上不可见。详见敌人描述符模块。另有 @Spy 撰写的一份相关指南，但它针对的是较早的 CD2 版本，内容已经过时，仅供参考。
    英文原文
    A: It depends on which features your difficulty uses. Some CD2 features must be replicated to clients — the Scale enemy control and enemy appearance (materials) for example. The enemy module has two forms and they cannot be used together: Enemies replicates those characteristics to clients, but in exchange every client must have CD2 installed or they get disconnected when the mission starts. Switch to EnemiesNoSync and clients no longer need CD2, at the cost of those features not being visible to them. See Enemies / EnemiesNoSync for the details. There is also a guide by @Spy on this topic, though it was written for an older version of CD2 and is now out of date.
  • 问：Vars 是什么？什么时候该用？
    英文原文
    Q: What is Vars? When should I use it?
  • 答：Vars 是 CD2 的全局变量池。当同一个值需要在多处反复计算、或需要在模块之间共享时就该用它：定义一次，之后在任何接受该类型的字段里用 {"Var": "变量名"} 引用即可。它支持模块间通信，其中的 Watch 字段还能把变量值显示在界面上，因此也是调试逻辑的推荐做法。详见《模块 · Vars》。
    英文原文
    A: Vars is CD2's global variable pool. Use it when the same value would otherwise be recomputed in several places, or needs to be shared between modules: define it once, then reference it as {"Var": "name"} in any field that accepts that type. It also supports module-to-module communication, and its Watch field shows the value in the GUI, which makes it the recommended way to debug logic. See Modules · Vars.
  • 问：为什么我原来的 CD1 难度文件不能与 CD2 兼容？
    英文原文
    Q: Why aren't my original CD1 difficulties compatible with CD2?
  • 答：Custom Difficulty v2 是个完全重构的版本，采用 top level 来标识独立模块。如果你需要将 CD1 的内容迁移到 CD2,可以使用自动转换脚本。或者，你也可以在 PDRG 论坛发布文件，寻求他人协助运行脚本或手动迁移。
    英文原文
    A: Custom Difficulty v2 is a complete redesign and it uses top level names to denote independent modules. If you need to port something from CD1 to CD2, there is a script that automatically does the translation. Alternatively, you can post the file in the PDRG forums asking for help in running the script or making the port yourself.
  • 问：我写的 Mutator 没反应 / 一直是初始值，怎么查？
    英文原文
    Q: My mutator does nothing / always returns the initial value. How do I debug it?
  • 答：绝大多数情况是这一个原因：把数值型 Mutator 直接喂给了要求布尔信号的字段（In、If 的 Condition 等）——数值输出必须先经 TriggerOnChange 转换。通用做法：先用 Vars 定义逻辑，并打开 Watch 字段让数值显示在界面上，调通之后再接上实际效果。详见《写作提示与常见错误》。
    英文原文
    A: Two mistakes account for most of these cases. First, feeding a numeric mutator into a field that expects a boolean signal (In, If's Condition …): numeric output has to go through TriggerOnChange first. In general, define your logic with Vars and turn on the Watch field so the value is shown in the GUI, then wire it to the actual effect once it behaves. See Tips.
  • 问：它与 MEV/DEA 等敌人扩展模组兼容吗？
    英文原文
    Q: Is this compatible with MEV/DEA and other similar expansion mods?
  • 答：是的，它与目前最常见的敌人扩展模组完全兼容！
    英文原文
    A: Yes, this is fully compatible with the most common enemy expansion mods!
  • 问：我的难度能给别人玩吗？怎么判断能不能公开匹配？
    英文原文
    Q: Can I share my difficulty with other players?
  • 答：可以，需要决定的是「是否允许没装 CD2 的人加入」，也就是所谓公开匹配。CD2 的部分功能必须同步给客户端，例如 Scale 缩放控制或自定义敌人材质；若用到了它们，客户端就必须安装 CD2，否则任务开始时会被断开。敌人模块提供了取舍：用 Enemies 功能最全，用 EnemiesNoSync 则谁都能进。另外 CD2 同样适用于深潜，无需额外模组，也可以在 《模块》 里用 NextDifficulty 为每一阶段设置不同难度。详见《敌人描述符模块》与 @Spy 的《On Pubbing With CD2》。
    英文原文
    A: Yes. What you need to decide is whether it should be playable by people who do not have CD2 installed — that is what "pubbable" means. Some CD2 features must be replicated to clients, such as the Scale enemy control or custom enemy materials; if your difficulty uses them, every client needs CD2 or they will disconnect at mission start. The enemy module gives you the choice: use Enemies for the full feature set, or EnemiesNoSync so that anyone can join. Note that CD2 works fine in Deep Dives as well — no extra mod needed, and you can set a different difficulty per stage via NextDifficulty in Modules. See Enemies / EnemiesNoSync and @Spy's On Pubbing With CD2.
  • 问：难度文件该放在哪里？游戏怎么读到我写的难度？
    英文原文
    Q: Where do I put a difficulty file? How does the game find it?
  • 答：把 JSON 直接粘贴到局内的 CD2 面板里。如果没有 JSON 报错或其它问题，点 Save 就保存了——不需要自己去管理什么文件夹。
    英文原文
    A: Paste the JSON into the in-game CD2 panel. If it parses without errors and nothing else complains, pressing Save stores it — there is no separate folder to manage.
  • 问：改完难度文件，为什么游戏里没变化？
    英文原文
    Q: I edited the file but the game shows no change. Why?
  • 答：没进游戏前点 Save 就好。不建议进了游戏之后再切换难度。
    英文原文
    A: Save before entering the game. Switching difficulty mid-mission is not recommended — make your edits and press Save while still in the lobby.
  • 问：有没有现成的难度可以参考或学习？
    英文原文
    Q: Are there finished difficulties I can learn from?
  • 答：有——本站收录了作者自己写的一个难度：物竞天择 · Natural Selection（Hazard 9）。该页可下载其 JSON，对照文档一起看。
    英文原文
    A: Yes — this site hosts one written by its author: Natural Selection, a Hazard 9 difficulty. Its JSON can be downloaded from that page and read alongside the documentation.
  • 问：CD2 会拖慢游戏吗？敌人很多会卡吗？
    英文原文
    Q: Does CD2 slow the game down? Will lots of bugs cause lag?
  • 答：CD2 本身占用很小。是否卡顿取决于难度本身——主要看虫子同屏数量多不多；此外，大量改动敌人材质等外观内容也会增加负担。极端的生成数量会掉帧，这一点和 CD1 是类似的。
    英文原文
    A: CD2 itself has a very small footprint. Whether it lags depends on the difficulty — it comes down to how many creatures are on screen at once, and heavy use of custom enemy materials also adds cost. Extreme spawn counts cost frames, much as they would in CD1.
